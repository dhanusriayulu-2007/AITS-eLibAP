Help & support

Common questions about using eLibAP, troubleshooting, and how to get in touch.

Troubleshooting

COMMON ISSUE

Pages say "Start the Java server"

eLibAP's videos, textbooks, newspapers, books and events are all served by a small Java API on port 8080. If a page shows this message, the server isn't running yet.

From the project folder, run: bash server/run.sh (or compile/run Main.java directly), then reload the page.

COMMON ISSUE

CORS error in the browser console

This happens when you open an HTML file directly (file://) instead of through a web server.

Serve the site with python3 -m http.server 3000 from the project folder and open http://localhost:3000 instead.

COMMON ISSUE

Port 8080 already in use

Another process is already listening on that port. Either stop it, or change the port number in server/Main.java and update the API constant at the top of each page's script.

COMMON ISSUE

A textbook or video link doesn't open

All PDF/video links point to official third-party sources (AP SCERT, TS SCERT, NCERT, NTA, YouTube, DIKSHA). If a state government site is temporarily down, try again later or use the "Visit Portal" link on that card.

Frequently asked questions

What is eLibAP?

A free digital library for students and communities in Andhra Pradesh and Telangana. It links to open platforms (YouTube, DIKSHA, Open Library, Internet Archive, official government portals) rather than hosting content itself.

Which classes/boards are covered?

AP Board and TS Board, from Kindergarten through Intermediate (11–12), plus competitive exam prep (NTSE, Science Olympiad, NMMS, EAPCET, JEE Main, NEET). See the Educational section and its Kindergarten / Primary / Secondary / Intermediate / Competitive Exams pages.

Do I need to sign up to use the site?

No — all textbooks, videos, newspapers, books and events are free to browse without an account. Signing up (top-right) just saves your name so the site can greet you; it's stored in your browser only, not on a server.

How often is content updated?

Textbook/video/newspaper/book listings are stored in JSON files under data/ and read fresh on every request — no caching, no rebuild needed.

I found a broken or outdated link — what do I do?

Use the "Ask a Librarian" contact below and mention the page and item title. Government portals occasionally rename files, and we periodically re-verify links.
